Acerca de Coffee Place Studio

Coffee Place Studio es un proyecto enfocado en crear herramientas prácticas, moderación y seguridad automatizada para servidores de Discord.

El bot está diseñado para facilitar la administración diaria, ayudando a mantener los servidores organizados y seguros para todos los miembros.

Características Principales

El bot implementa sistemas diseñados específicamente para mantener las comunidades ordenadas y protegidas:

Logs Separados

Canales de registro independientes para moderación, miembros, entradas, salidas y cambios de perfil en tiempo real.

Ayuda Paginada

Un comando de ayuda organizado y fácil de navegar mediante botones interactivos.

Sistema de Sanciones

Acumulación de advertencias con lógica de expulsión automática al llegar al límite establecido y avisos por mensaje directo.

Anti-Raid Estricto

Protección contra bots no autorizados o ingresos masivos sospechosos para cuidar el servidor.

Condiciones del Servicio

Al invitar, configurar o utilizar Coffee Place Studio en cualquier servidor de Discord, aceptas las siguientes Condiciones del Servicio. Si no estás de acuerdo con alguna de estas reglas, debes abstenerte de utilizar el bot y expulsarlo de tu servidor.

1. Uso del Servicio

Coffee Place Studio se proporciona tal cual es. Los creadores se reservan el derecho de modificar, actualizar o suspender funciones o comandos del bot cuando sea necesario.

2. Normas de Comportamiento

Queda prohibido:

  • Intentar vulnerar, dañar o alterar el código o los sistemas del bot.
  • Utilizar las herramientas de automatización o moderación para hostigar o realizar acciones maliciosas contra otros usuarios o servidores.
  • Aprovecharse de errores o fallos para saltarse las restricciones del bot.

3. Limitación de Responsabilidad

Los creadores de Coffee Place Studio no se hacen responsables por:

  • Pérdidas de datos o fallos derivados de una mala configuración de permisos por parte del staff del servidor.
  • Sanciones o baneos aplicados por moderadores humanos que usen mal los comandos del bot.
  • Caídas temporales del servicio debido a mantenimientos en la nube.
Nota: Los administradores de cada servidor son los únicos responsables de supervisar las sanciones y el uso del bot en su comunidad.

Política de Privacidad

En Coffee Place Studio respetamos la privacidad de los usuarios de Discord. Esta sección explica qué información se maneja al usar el bot.

1. Datos que se Recopilan

Para que el bot pueda funcionar correctamente, procesa únicamente los siguientes datos dentro de Discord:

  • IDs Únicos: IDs de usuarios, servidores, canales y roles necesarios para ejecutar comandos y verificar permisos.
  • Registros de Logs: Información sobre sanciones, razones, cambios de apodo o nombre de usuario, y entradas/salidas enviadas a los canales de registro configurados.
  • Interacciones: Comandos ejecutados para hacer funcionar los menús interactivos.

2. Datos que NO Recopilamos

Coffee Place Studio no recopila ni lee:

  • Contenido de chats generales o mensajes privados (DMs).
  • Información personal del mundo real (nombres reales, correos, contraseñas o ubicación).

3. Almacenamiento

Los datos operativos se manejan de manera segura y no se comparten con terceros. Los registros enviados a los canales de logs están bajo el control absoluto de los administradores del servidor.
